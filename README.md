# Consulting App (Laravel)

A simple internal project management system built with Laravel.

## 🚀 Features

- Clients management
- Projects management
- Tasks with assignment to users
- My Tasks page (per user)
- Overdue tasks tracking
- Search & filters
- File uploads (project documents)
- Comments on tasks (collaboration)
- Roles & permissions (Admin / Employee)
- Dashboard with statistics

---

## 🧑‍💻 Tech Stack

- Laravel
- MySQL
- Blade
- Tailwind CSS
- Spatie Laravel Permission
